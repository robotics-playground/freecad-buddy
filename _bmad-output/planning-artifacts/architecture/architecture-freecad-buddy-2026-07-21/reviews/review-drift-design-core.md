# Drift Review — Core Design Docs vs Spine

Verdict: **not clean**. 19 findings. 6 CRITICAL, 8 HIGH, 5 MEDIUM.

Two clusters dominate. First, `integration-mcp-freecad.md` uses a **different module-path vocabulary** than every other doc and than the installed code (`contracts/rpc_wire.py`, `adapters/render.py`, `hosts/headless/run_server.py`, `hosts/gui_addon/pump.py` for the Qt marshal). Second, the spine's AD-10 **≤1024 px** render budget is contradicted by every design doc that states a budget (all say ≤1920 px) — the spine was never amended.

## Note on severity of the module-path cluster

Findings 1, 2, 5, 8, 9, 10, 11 all trace to `integration-mcp-freecad.md` carrying an earlier layout vocabulary. They are graded individually because `project-structure.md` §2.3 L176 and §7 L280 specify `check_imports.py` whitelists **by exact path** — a wrong path in the authoritative wire-design doc becomes a silently disabled CI check, not just a typo.
