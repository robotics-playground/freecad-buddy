## Goal

Make the bridge do what the design says when a real agent drives it through the real FreeCAD 1.1.4 window: queries return what matches, mutations that should fail do fail, rollback is proven, and every report states what actually happened. The UAT suite and its harness must describe the product as it is, and a full UAT run must become cheap enough to repeat (scripted runner plus an independent FreeCAD probe). Trigger: UAT run `2026-10-03-04` (HEAD `bece7ac`) was the first to run all of TC-01..TC-14 and left Gate 1 red: 34 of 251 scenarios FAIL, 29 on product defects F-01..F-33 (Critical 74.7 %, needs 100 %; High 79.1 %, needs ≥ 95 %). Most defects are code that does not match an AD that is already correct. The epic corrects shipped behaviour of Epics 1-3, 8 and 9; it opens no gate and reopens no epic. Epic 4 is paused: Story 4.3 starts only when Epic 10 is done.

## Technical Decisions

- **AD-5 mutation protocol:** snapshot → `openTransaction` → op → `recompute()` → post-verify → commit. Post-verify: (1) recompute clean, (2) `verify_shape` on touched shapes, (3) `verify_sketch` on every touched sketch and every sketch in the `OutList` of a touched non-container object (Body membership alone never pulls a sketch in), (4) TNP audit. The audit runs on every path where the op returned; an audit that did not run is `UNSUPPORTED`, never `CLEAN`. Abort path proves rollback by digest equality; snapshot-restore path proves it with `massprops_equal` over the same object names (reopen re-serializes B-rep bytes). Feature input refusals are `INVALID_INPUT` before the bracket opens.
- **AD-6 fingerprint:** SHA-256 over per-object shape bytes sorted by `Name`, plus quantized mass properties, tagged by serializer. A null `Shape` enters as `sha256(b"")` with zeroed mass properties; an object with no `Shape` attribute stays out. FCStd/XML hashing banned as identity oracle.
- **Read-only-after-render guard:** compare `massprops_equal(before, after)` (volume, area, com, principal moments; not bbox, not digest). On a dirty document (Touched/Invalid/Error) the guard is skipped and the render reports `render.dirty_document: true`.
- **Audit log:** each mutation writes a `before` and `after` line from inside `run_mutation`, both with the full-parameter digest and real fingerprints; a call refused before the bracket gets its pair from the adapter. `debug_exec` writes its `before` line ahead of execution.
- **AD-8:** sketch PASS iff `solve()` returns 0, `FullyConstrained` and `DoF == 0`, read after `recompute()` and `solve()`. Hard fail on conflicting, malformed, fully redundant, over/under-constrained or degenerate; partial redundancy only warns.
- **AD-17:** closed status set `OK | SPEC_FAILED | RECOMPUTE_ERROR | TIMEOUT | OOM_KILLED | WORKER_CRASHED | INVALID_INPUT`. Input faults are `INVALID_INPUT`. AD-28: schema changes are additive-only within a major; JSON Schemas are generated and drift-checked.
- **AD-9 STEP export pair:** every `export_*` completes only through its paired `verify_export_*` re-import. `export_step` `ap` enum is `AP214 | AP242`, default `AP242`.
  - Pin per call through OCC statics, never ambient defaults: `write.step.unit = MM`; `write.step.schema` takes the OCC enum name: `AP242DIS` (AP242), `AP214IS` (AP214), `AP203` (AP203). Bare `AP242` is refused by `Part.setStaticValue`. `TopoShape::exportStep` reads only the statics.
  - Never write the user's `Mod/Part/STEP` `Scheme` preference. Statics are process-global, so after every `exportStep`, success or raise, restore them in one `finally`: schema to `Scheme` when it is in `Part::supportedSTEPSchemes()` (`AP203`, `AP214CD`, `AP214DIS`, `AP214IS`, `AP242DIS`), else `AP214IS` (OCC default); unit to the value read with `Part.exportUnits()` before the pin. No Python getter exists for the schema static: a schema a macro set directly is overwritten (stated limitation).
  - Verify: re-import into a fresh document; `isValid()` + `check()` pass; volume within ±0.1 %, bbox diagonal and centre of mass within tolerance; face/edge/solid counts equal; check `export_step.schema`: first identifier of the file's `FILE_SCHEMA` (header before `DATA;`, may span lines) equals the recorded `ap` schema: `AP242_MANAGED_MODEL_BASED_3D_ENGINEERING_MIM_LF`, `AUTOMOTIVE_DESIGN` (AP214), `CONFIG_CONTROL_DESIGN` (AP203). It reads the file, never a setting. No `FILE_SCHEMA` fails with `measured: null`.
- **AD-13 / AD-19 / AD-20:** pass/fail by deterministic code or an independent grader (the 10.7b probe included, with its own sensitivity set). Every call carries an explicit document handle.
- **AD-25:** bridge files live in a session-scoped workdir; temp files under `<workdir>/tmp/FCB_TMP_session_<pid>_<token>/`. Sweep touches only `FCB_TMP_` entries of dead hosts.
- **AD-26 / AD-27:** one client session; second gets `-32000` busy. `TIMEOUT` quarantines the session until the in-flight op returns and rolls back; no mutation is retried automatically. The method registry is the single source of `timeout_s`.
- **Render (constructed scene):** each call builds its own Coin scene; hiding is "not adding the subgraph", so `include`/`exclude`/styles never touch `Visibility`, the modified flag or the live viewport. Style = per-object `SoSeparator` with prepended `SoMaterial` that overrides only the fields it writes (transparency 0–1, diffuse colour optional).
  - **Default set** (no `include`) is the shared predicate `is_default_renderable` in `usecases/screenshot.py`: own `Visibility` true; a non-null `Shape`, or for `Mesh::Feature` a `Mesh` with facets; excludes `PartDesign::Body` and every datum/origin type (derived from `App::DatumElement`, `App::LocalCoordinateSystem` or `Part::Datum`). A visible sketch is in the set; a hidden one is not.
  - **Body in `include`** draws its Tip, reported under the Body name; a Body with no Tip draws nothing.
  - `scene.rendered_objects` lists only names whose subgraph drew something (non-empty bbox). `render.empty_scene: true` when nothing drew: no PNG written, `resource_link` null.
- **AD-34 lighting:** exactly one off-axis `SoDirectionalLight` plus ambient. Every named camera plus `custom` renders a face tone differing from background by ≥ 24/255 on one channel and within `[20, 235]` on every channel, ≥ 500 interior samples. MCP render need not match live viewport shading.
- **AD-29:** live camera access only through `ViewportPort` (in `contracts/render.py`, implemented in `hosts/gui_addon/`); no viewport means the capability is unavailable, never a fabricated verdict.
- **AD-30 framing:** project the 8 union-bbox corners of the `is_default_renderable` set through `getPointOnViewport` (not `getPointOnScreen`); `fits` false iff any corner is outside `getSize()`, the whole 3D view. Union skips any box with a coordinate of magnitude `>= 1e99` (infinite OCC shapes); a mesh's box is `Mesh.BoundBox`. Hidden-container children count as visible to both render and framing (stated limitation; change both or neither).
- **Fit = verdict routine:** fit and verdict share the corner projection in `usecases/framing.py` (`projected_hull`, `measure_framing`); an analytic extent estimate is banned (biased low for compact shapes). Three passes inside one `_animation_suspended` block: (1) `viewIsometric` + `fitAll(1.0)`, project the measured set, box its 2D hull; (2) `boxZoom` on that hull expanded about its centre by `1 / _FILL_FRACTION`, Y flipped (`y_box = height - y`) — not `fitAll(factor)`, because `fitAll` centres on the Coin scene box, which includes a drawn datum plane; (3) re-project for the AD-31 verdict. Cannot suspend animation → `SPEC_FAILED`. Empty measured set (datum-only) → refuse before any camera move.
- **AD-31:** `view_fit_viewport` is view-only, confirm-exempt, audited with `camera_before`; requires `doc` and refuses with `INVALID_INPUT` (naming both) when it is not the viewport's document. `fitted: true` requires its own post-fit `fits: true`, else `SPEC_FAILED` carrying the `framing` block.
- **AD-32 `FramingVerdict`:** top-level envelope key `framing` = `{fits, ratio, checked: computed|cached|unavailable, stale_reason}`. `ratio` = larger `extent / viewport_extent` of the projected 2D hull; `None` with `fits: false` if a corner exceeds 4× the viewport dimension. No viewport → block omitted; projection failed → `fits: null`, `checked: "unavailable"`. Non-`OK` status omits the block, except AD-31's post-fit `SPEC_FAILED`. Cache key `(fingerprint, camera_string, viewport_size, active_view_id)`. Read sits after commit, outside the AD-5 bracket.
- **AD-33:** bridge never fits spontaneously; it warns, and moves the camera only on `view_fit_viewport`.
- **AD-1 rings:** imports point inward only, `contracts/` ← `usecases/` ← `adapters/` ← `hosts/`. The 10.7b probe lives outside `src/freecad_buddy`. AD-35: no AI workflow in shipped code.
